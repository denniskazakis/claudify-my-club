# claudify-my-club

Dieses Repository ist ein offenes Experimentierlabor für Social-Media-Arbeit.
Hier entstehen Ideen, Skripte und Workflows rund um das Planen, Erstellen und Auswerten von Inhalten für soziale Netzwerke.
Der Schwerpunkt liegt darauf, wiederkehrende Aufgaben im redaktionellen Alltag mit KI-Unterstützung zu automatisieren.
Alles hier ist bewusst als Versuchsaufbau gedacht und wird laufend überarbeitet, verworfen oder neu aufgesetzt.
Wer vorbeischaut, darf gerne mitlesen, Ansätze übernehmen und eigene Varianten daraus entwickeln.
