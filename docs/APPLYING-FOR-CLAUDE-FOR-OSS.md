# Applying for Claude for Open Source

This repository is meant to be honest evidence, not a trick.

## Strong application evidence

- Real users or community teams who copied the templates.
- Examples adapted for multiple club types.
- Issues or pull requests from outside contributors.
- Clear README and install path.
- Public releases with changelog notes.
- No fake stars, fake downloads, or fake contributors.

## Suggested application framing

Claudify My Club helps small volunteer-run clubs use Claude safely for event communication, content planning, post-event recaps, and sponsor updates. It packages reusable Claude project folders, prompts, and review gates so organizers can get useful drafts without publishing unverified facts or unapproved media.

## Honest limitations

This project is early. It does not yet prove large ecosystem impact. The strongest near-term evidence is real usage by clubs and external contributors improving templates.
