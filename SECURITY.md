# Security and Privacy

This repository is intentionally public and must not contain private operational data.

Do not commit:

- API keys, OAuth tokens, cookies, passwords, or `.env` files.
- Real participant lists, guardian details, DMs, voice notes, or raw consent forms.
- Unapproved images or videos of identifiable people.
- Private sponsor contracts or invoices.
- Full calendar exports containing personal information.

If you find sensitive data in this repository, open a private security report or contact the maintainer directly. Do not create a public issue with the secret value.
