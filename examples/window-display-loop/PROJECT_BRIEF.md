# Project Brief — Window Display Loop

## Goal

Storyboard a 30-second silent loop for a physical window display.

## Constraints

- Vertical 9:16
- No audio
- Six modules of 5 seconds each
- Huge typography readable from distance
- Permanent call-to-action area

## Required outputs

- six-module storyboard
- headline options
- motion notes
- design risk list

No real logos or faces are included in this sample. Replace with approved brand assets only.
