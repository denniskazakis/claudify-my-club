# Post-Event Clip Harvest

## Goal

Sort raw event moments into READY, HOLD, and REVIEW before creating clips.

## How to use with Claude

1. Open this folder in Claude Code or attach it to Claude.
2. Ask: `Read CLAUDE.md and PROJECT_BRIEF.md. Produce the requested outputs as drafts.`
3. Ask Claude to run `REVIEW_CHECKLIST.md` before you use anything publicly.
4. Human approves before publishing.

## Files

- `CLAUDE.md` — local project instructions
- `PROJECT_BRIEF.md` — facts and constraints
- supporting Markdown files — sample source material
